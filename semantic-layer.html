시맨틱 레이어 생성

한국어원문 기준 2026-10-11

Semantic View를 통해 에이전트가 비즈니스 로직을 이해할 수 있는 ‘지도’를 제공합니다.

Cortex Analyst 생성#

이 도구는 SQL을 생성하여 에이전트가 Snowflake의 정형 데이터를 쿼리할 수 있도록 합니다. Semantic View를 사용해 ‘제품명’, ‘매출’ 같은 비즈니스 개념을 Snowflake 계정의 실제 테이블 및 컬럼에 매핑합니다. 이러한 추상화 덕분에 테이블 이름이 복잡하거나 임의의 명명 규칙을 따르더라도 LLM이 데이터를 효과적으로 쿼리하는 방법을 이해할 수 있습니다.

  1. Snowsight에서 AI & ML > Analyst로 이동한 다음 오른쪽 위의 Create with Autopilot in Workspaces을 클릭합니다.
  2. Create with Autopilot을 클릭합니다.
  3. Provide context 페이지에서 Skip을 클릭합니다.

  4. 다음과 같이 설정합니다.

    • Select tables: DASH_DB_SI.Retail의 모든 테이블을 선택합니다(테이블 5개와 Dynamic Table 1개).
    • Select columns: 모든 컬럼을 선택합니다.
    • Name: SEMANTIC_VIEW
    • Target name: SEMANTIC_VIEW
    • Location to store: DASH_DB_SI.Retail
  5. Deploy를 클릭하고, Semantic View가 생성되는 동안 기다립니다.
  6. MARKETING_CAMPAIGN_METRICS 섹션으로 스크롤하고 수정 아이콘(연필모양)을 클릭합니다.
  7. Primary Key에 Category를 입력하고 오른쪽 상단 체크버튼을 클릭합니다.

  1. 아래로 스크롤한 다음 Relationships의 +를 클릭합니다.

  2. 다음과 같이 설정합니다.

    • From Table: ENRICHED_MARKETING_INTELLIGENCE
    • To Table: MARKETING_CAMPAIGN_METRICS
    • Relationship Type: Many to One
    • From Column: PRODUCT_NAME
    • To Column: CATEGORY

  3. 체크 아이콘을 클릭하여 관계를 추가합니다. 오른쪽 상단 Deploy changes를 클릭하고 Deploy버튼을 클릭하여 변경사항을 반영합니다.

Cortex Search Service 생성#

이 도구는 고객 지원 티켓, Slack 대화, 계약서 같은 비정형 텍스트에서 에이전트가 정보를 검색하고 가져올 수 있게 합니다. Cortex Search로 텍스트 ‘청크’를 인덱싱하고 쿼리하여 에이전트가 검색 증강 생성(RAG)을 수행할 수 있도록 합니다.

  1. Snowsight에서 AI & ML > Search로 이동합니다.
  2. 역할과 웨어하우스가 SNOWFLAKE_INTELLIGENCE_ADMIN와 DASH_WH_SI로 설정되어 있는지 확인합니다.

  3. 다음과 같이 설정합니다.

    • Service database & schema: DASH_DB_SI.Retail
    • Service name: campaign_search
    • Select data: marketing_campaign_metrics
    • Select search column: campaign name
    • Select attribute: Select all
    • Select columns: Select all
    • Embedding model: snowflake-arctic-embed-l-v2.0
    • Warehouse for indexing: DASH_WH_SI
  4. create를 클릭한 다음 오른쪽 위의 새로 고침 아이콘을 클릭합니다. Serving 상태가 INITALIZING에서 ACTIVE로 바뀝니다.
