From Zero to Agents · AI 에이전트 실습 · 01 / 09

개요

한국어원문 기준 2026-10-11

이 실습에서는 Snowflake Cortex AI의 감성 분석과 분류 기능으로 원시 데이터를 실행 가능한 인사이트로 전환합니다. Cortex AI와 Dynamic Table을 직접 사용해 AI 기반 데이터 보강을 자동화하고 신뢰할 수 있는 시맨틱 레이어를 구성합니다. 정형 데이터와 보강된 비정형 고객 피드백을 함께 활용하면서 엔터프라이즈 보안 기준을 유지하는 마케팅 및 영업 인텔리전스 에이전트의 아키텍처를 배웁니다.

학습 내용#

  • Cortex AI Function을 활용한 감성 분석과 텍스트 분류
  • AI 기반 데이터 보강 파이프라인을 자동화하는 Dynamic Table 생성
  • 기술적인 컬럼을 비즈니스 용어에 매핑하는 Semantic View 구성
  • Analyst와 Search 도구를 갖춘 AI 에이전트 생성 및 설정
  • Dynamic Data Masking을 이용한 역할 기반 접근 제어(RBAC) 구현

구축할 결과물#

  • Cortex AI와 Dynamic Table을 이용한 자동화된 AI 데이터 보강 파이프라인
  • 데이터를 비즈니스 친화적으로 추상화하는 Semantic View
  • Cortex Analyst와 Cortex Search 기반의 마케팅 및 영업 인텔리전스 에이전트
  • 마스킹 정책을 활용한 엔터프라이즈 수준의 보안 제어

사전 요구 사항#

  • 데이터베이스, 스키마, 테이블, 가상 웨어하우스 오브젝트를 생성할 수 있는 역할이 있는 Snowflake 계정
  • SQL에 대한 기본 지식
  • Snowsight(Snowflake의 웹 인터페이스) 접근 권한
