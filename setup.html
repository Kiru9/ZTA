환경 설정 및 데이터 로딩

한국어원문 기준 2026-10-11

스포츠 및 아웃도어 용품을 판매하는 가상의 소매 기업에서 마케팅 팀으로 일한다고 가정해 보겠습니다. 이 기업에는 유료 광고의 캠페인 성과부터 고객 피드백까지 다양한 데이터가 풍부하게 쌓여 있습니다.

팀이 직면한 문제는 다음과 같습니다.

  1. 캠페인 성과 데이터와 고객 피드백이 서로 분리되어 있습니다.
  2. 고객 피드백은 비정형 데이터이며 분석되지 않은 상태입니다.
  3. 분석가가 이 데이터에서 직접 인사이트를 얻기 어렵습니다.

이 문제를 해결하기 위해 다음을 구축합니다.

  1. Cortex AI로 원시 대화 기록을 구조화된 감성 점수로 변환합니다.
  2. Dynamic Table로 처리를 자동화하여 새 피드백이 들어올 때마다 데이터를 최신 상태로 유지합니다.
  3. Semantic View로 캠페인 지표와 고객 피드백을 하나의 모델로 연결합니다.
  4. Snowflake CoWork에서 분석가가 자연어로 질문할 수 있도록 합니다.

설정 방법#

제공된 setup.sql 스크립트로 안전한 기반 환경을 구성합니다. 이 스크립트는 역할과 웨어하우스 생성, 공개 S3 버킷에서 마케팅 데이터를 수집하는 작업을 자동화합니다.

Snowsight의 SQL Worksheet에서 setup.sql을 실행합니다.

프로비저닝되는 항목#

  • 인프라: dash_wh_si 웨어하우스와 snowflake_intelligence 데이터베이스를 생성합니다.
  • 데이터 수집: 정형 지표(캠페인 지출, 제품 판매)와 비정형 대화 기록(support_cases)을 로드합니다.
