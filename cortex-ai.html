Cortex AI로 데이터 보강

한국어원문 기준 2026-10-11

Cortex AI를 이용한 AI 데이터 보강은 표준 SQL 쿼리 안에서 내장 생성형 AI Function을 직접 사용하여 데이터를 분석하고 변환하며 가치를 더하는 과정입니다.

Snowflake에서는 Snowflake Cortex AI가 이 기능을 제공합니다. 데이터를 외부 서비스로 옮기거나 복잡한 인프라를 관리하지 않고도 고성능 대규모 언어 모델(LLM)을 실행할 수 있습니다.

작동 방식#

기존에는 감성 분석을 수행하거나 텍스트에서 이름을 추출하려면 데이터를 Python 환경이나 타사 API로 내보내야 했습니다. Cortex AI Function을 사용하면 LLM을 SUM()이나 AVG() 같은 일반 SQL 함수처럼 다룰 수 있습니다.

주요 Cortex AI Function#

Snowflake는 데이터 보강을 간편하게 수행할 수 있는 여러 작업별 함수를 제공합니다.

함수설명
SNOWFLAKE.CORTEX.AI_SENTIMENT(text)감성 점수를 반환합니다.
SNOWFLAKE.CORTEX.AI_SUMMARIZE(text)긴 문서나 대화 기록을 간결하게 요약합니다.
SNOWFLAKE.CORTEX.AI_EXTRACT_ANSWER(text, question)비정형 텍스트에서 특정 질문에 대한 답을 찾습니다.
SNOWFLAKE.CORTEX.AI_CLASSIFY(text, categories)텍스트를 미리 정의한 라벨(예: ‘환불’, ‘불만’, ‘영업 문의’)로 분류합니다.
SNOWFLAKE.CORTEX.AI_TRANSLATE(text, source, target)텍스트를 다른 언어로 번역합니다.

AI 데이터 보강을 사용하는 이유#

  • 확장성: Snowflake의 탄력적인 컴퓨팅(웨어하우스)으로 수백만 로우의 비정형 텍스트를 처리합니다.
  • 보안: 데이터가 Snowflake의 보안 경계를 벗어나지 않으며, 이는 GDPR/HIPAA 규정 준수에 중요합니다.
  • 자동화: 이 함수를 Dynamic Table 안에서 사용하면 새 데이터가 들어올 때 자동으로 AI 데이터 보강이 이루어집니다.
  • 낮은 진입 장벽: SQL을 아는 분석가라면 Python이나 PyTorch를 배우지 않고도 고급 데이터 사이언스 작업을 수행할 수 있습니다.

AI 에이전트와의 연계#

AI 데이터 보강은 ‘전처리’ 단계입니다. 데이터를 먼저 보강하면 다음과 같은 이점이 있습니다.

  1. 에이전트가 모든 원시 대화 기록을 읽을 필요가 없습니다.
  2. sentiment_score 컬럼만 쿼리하여 불만족 고객을 찾을 수 있습니다.
  3. 그 결과 에이전트의 속도와 정확도가 높아지고 비용이 줄어듭니다.

트렌드 추출#

Cortex AI Function으로 ‘다크 데이터’인 원시 대화 기록을 분석 가능한 트렌드로 전환합니다. 고객 피드백에 감성 분석을 수행하여 측정 가능한 특성을 만듭니다.

코드 / 텍스트
USE DATABASE DASH_DB_SI;
USE SCHEMA RETAIL;
UPDATE support_cases SET product = 'Fitness Wear' WHERE product = 'ThermoJacket Pro';
SELECT 
    title,
    SNOWFLAKE.CORTEX.AI_SENTIMENT(transcript) AS sentiment_score,
    SNOWFLAKE.CORTEX.AI_CLASSIFY(transcript, ['Return', 'Quality', 'Shipping']) AS issue_category
FROM support_cases;

마케팅 데이터 업데이트#

왼쪽 아래의 프로필을 클릭하여 역할이 SNOWFLAKE_INTELLIGENCE_ADMIN으로 설정되어 있는지 확인합니다.

  1. marketing_data.csv를 다운로드합니다.
  2. Catalog > Database Explorer로 이동합니다.
  3. DASH_DB_SI.RETAIL.Tables.MARKETING_CAMPAIGN_METRICS를 엽니다. 데이터베이스가 보이지 않으면 데이터를 새로 고칩니다.
  4. 오른쪽 위의 Load Data를 클릭합니다.
  5. marketing_data.csv를 업로드하고 next, load를 차례로 클릭합니다.
  6. View table detail을 클릭하여 새로 업로드한 데이터를 확인합니다.
