지속적으로 데이터를 보강하는 파이프라인 생성

한국어원문 기준 2026-10-11

‘라이브’ 데이터 보강 파이프라인을 만들기 위해 Cortex AI Function과 Dynamic Table을 결합합니다. Snowflake가 새 데이터가 들어올 때 자동으로 처리하므로 수동 개입 없이 감성 점수와 분류 결과를 최신 상태로 유지할 수 있습니다.

라이브 데이터 보강 아키텍처#

일회성 데이터 보강 작업을 실행하는 대신 Dynamic Table을 정의합니다. 이 테이블은 원시 데이터의 변경 사항(예: 새 고객 피드백)을 지속적으로 감지하고 새로 추가되거나 변경된 로우에만 AI Function을 실행하는 구체화된 뷰 역할을 합니다.

데이터를 보강하는 Dynamic Table 생성#

캠페인 지표와 AI가 생성한 감성 점수를 자동으로 조인하는 Dynamic Table을 생성합니다.

코드 / 텍스트
USE ROLE SNOWFLAKE_INTELLIGENCE_ADMIN;
USE DATABASE DASH_DB_SI;
USE SCHEMA RETAIL;
CREATE OR REPLACE DYNAMIC TABLE enriched_marketing_intelligence
TARGET_LAG = '1 hours'
WAREHOUSE = dash_wh_si
AS
SELECT m.campaign_name, m.clicks, s.product AS product_name,
       CASE AI_SENTIMENT(s.transcript):categories[0]:sentiment::STRING
            WHEN 'positive' THEN 1
            WHEN 'negative' THEN -1
            ELSE 0
       END AS avg_sentiment
FROM marketing_campaign_metrics m
JOIN support_cases s ON m.category = s.product;

Catalog > Explorer > DASH_DB_SI.RETAIL.DYNAMIC TABLES.ENRICHED_MARKETING_INTELLIGENCE로 이동하여 Dynamic Table이 생성되었는지 확인합니다. 테이블이 보이지 않으면 새로 고침 버튼을 클릭합니다.
